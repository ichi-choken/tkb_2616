## 製品概要

**いま遊びたい仲間を見つけて、ゲームが変わっても、また誘える。**

「趣味仲間募集プラットフォーム（仮称）」は、複数のゲームや機種にまたがるプロフィールと、SNSからアクセスできる募集一覧を組み合わせた、ゲーム仲間を探すためのサービスです。

### 背景(製品開発のきっかけ、課題等）

「今日は少しだけ、気軽に誰かと遊びたい。でも、いつもの友人とは予定が合わない。」

私たちが着目したのは、こうした場面での仲間探しです。募集を探す場所がXやDiscordの各サーバーなどに分かれ、相手の情報もゲームや機種ごとのプロフィールに散らばっています。同じゲームを遊んでいると分かっても、「勝ちにこだわりたいのか、ゆるく楽しみたいのか」「いつ遊べるのか」「ボイスチャットを使うのか」を、投稿や個別のやり取りから確かめる必要があります。

一緒に遊べたあとも、相手がほかに何を遊んでいるか、いま何に熱中しているかが分からなければ、次に誘うきっかけをつかみにくいままです。

そこで、**一人の遊び方が分かるプロフィールと、いろいろな場所から人が集まれる募集を、一緒に扱える場所**を作ろうと考えました。仲間を探し始めるときの負担を減らし、一度遊んだ相手との次の機会まで支えることを目指します。

### 製品説明（具体的な製品の説明）

プロフィールには、遊んでいるゲーム、機種、熱量（ゆるく遊びたい〜本気で取り組みたい）、実力、遊べる時間をまとめます。ゲーム以外の趣味や好きなものも載せられ、相手との共通点を知るきっかけになります。

募集するときも参加するときも、ゲームや今回の条件を選びます。条件をそろえて扱うことで、参加者には自分に合う募集を、募集者には参加希望者との共通点や合う理由を示します。

想定する利用の流れは、次のとおりです。

1. **募集を出す。** ゲームや時間、人数、遊び方などを選んで公開し、リンク入りの招待状をX・Discord・LINEなど、普段使っている場所に共有します。サービス内だけで募集することもできます。
2. **合う募集を選ぶ。** 参加したい人はリンクをブラウザで開き、その募集と、同じゲームのほかの募集を比較できます。アプリのインストールやアカウント登録をせずに、参加希望を送れます。
3. **承認されたら合流する。** 募集者が参加希望を確認して承認すると、参加が確定します。登録された部屋番号をコピーしたり、招待URLを開いたりして合流します。参加者のゲーム内IDが必要な募集では、募集者がそのIDを使ってゲーム側で招待します。
4. **次の遊びにつなげる。** 遊び終わったあと、双方の同意で「つながり」を残せます。相手が遊んでいるほかのゲームや新しい募集を見て、また誘うきっかけにできます。

### 特長

#### 1. どの募集リンクからも、同じゲームの募集が見える

このサービスで作った募集は、共有先にかかわらず、ゲームごとの一覧にまとまります。リンクを開くと、元の募集が先頭に表示され、その下に同じゲームのほかの募集が並びます。

参加者は、一つのリンクを入口に、自分の条件に合う募集を探せます。募集者にとっても、自分の投稿を直接見ていない人に、ほかの募集リンクを通じて見つけてもらう機会が生まれます。

#### 2. ゲームや機種をまたいで、「いまの遊び方」が伝わる

一つのプロフィールに複数のゲームと遊び方をまとめ、「同じくゆるめ」「遊べる時間が近い」といった合う理由を表示します。参加前に、相手と一緒に遊ぶ場面を想像しやすくします。

Steam連携で取得できるプレイ時間などは自動更新し、入力の手間を減らす設計です。記録から推定した熱量は本人が直せるため、自動で補った情報にも自分の意向を反映できます。

#### 3. 一度遊んだ相手を、別のゲームにも誘いやすい

つながった相手について、遊んでいるゲーム、熱量、遊べる時間を確認できます。相手が新しく募集を出したときには知らせが届き、その募集から次の参加につながります。

「このゲームで一度遊んだ人」のほかの一面も分かることで、遊ぶゲームが変わっても、仲間との関係が続くことを目指します。

### 解決出来ること

| 仲間探しの困りごと | この製品で目指す変化 |
| --- | --- |
| 募集を探す場所が分かれていて、条件の合う募集を見つけにくい | 共有リンクや検索から、同じゲームの募集をまとめて比較できる |
| 同じゲームでも、熱量や時間、VCの希望が合うか分かりにくい | 条件と合う理由を参加前に確認し、遊び方の認識のずれを減らす |
| 募集文やDMで条件・合流方法を一から伝える負担がある | 条件の選択、参加希望、承認、合流情報の表示で、参加までのやり取りを進められる |
| 一度遊んでも、次に何を一緒に遊べるか分からない | 複数のゲームをまとめたプロフィールと募集の知らせから、次に誘うきっかけを得られる |

### 今後の展望

ブラウザから気軽に参加できる入口に加え、アプリ版では参加希望・承認・開始前の通知や、つながった相手の募集の知らせを受け取れるようにする計画です。

実際の利用を通じて、合う理由の表示が募集選びに役立つか、参加から合流まで迷わず進めるか、一緒に遊んだ相手を再び誘いやすいかを確かめ、改善につなげます。

### 注力したこと（こだわり等）

現段階では、次の点を設計で重視しています。実装上の工夫と検証結果は、開発後に追記します。

- **普段の遊び方と、今日の希望を分ける。** 募集・参加で選んだ条件はその回に使い、プロフィールへの反映は本人が「プロフィールにも保存」を選んだ場合に限ります。
- **承認した約束を大切にする。** 参加は募集者の承認で確定します。日時・機種・モード・VCの条件を変えたときは成立済みの相手に知らせ、改めて参加できるか確認します。未回答を理由に、自動で参加を取り消しません。
- **必要な相手に、最新の合流情報を届ける。** 部屋番号と招待URLは両方登録でき、変更した内容も成立済みの相手に反映します。募集者が「遊び終える」を押したときや開催中止時には、部屋番号・招待URL・参加者のゲーム内IDを双方の画面で非表示にします。
